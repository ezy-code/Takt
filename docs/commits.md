# Коммиты

| Тип        | Когда использовать                            |
| ---------- | --------------------------------------------- |
| `feat`     | новая функциональность                        |
| `fix`      | исправление бага                              |
| `docs`     | документация                                  |
| `style`    | форматирование, пробелы, без изменения логики |
| `refactor` | изменение структуры без изменения поведения   |
| `perf`     | оптимизация производительности                |
| `test`     | тесты                                         |
| `build`    | сборка, зависимости                           |
| `ci`       | GitHub Actions, GitLab CI и т.п.              |
| `chore`    | мелкие служебные изменения                    |
