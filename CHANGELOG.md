# Changelog

## v0.2.2

### English

- Tasks and notes unified into a single `items` entity with parent-child relationships
- Editor autosave
- Nested groups with record grouping support
- Canvas board with free task placement and group display
- Quick start from tray, auto-stop on system idle/suspend
- Full-content search in Spotlight
- Filter improvements
- Inline editing of timer entry start/end times
- Migration from better-sqlite3 to built-in node:sqlite
- Separate dev database from production
- Visual polish
- And much more

Full commit list: [v0.1.0...v0.2.2](https://github.com/ezy-code/Takt/compare/v0.1.0...v0.2.2)
